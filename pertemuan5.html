Definisi Unit Testing

Apa itu Unit Testing?

Unit Testing adalah metode testing yang menguji unit atau komponen terkecil dari perangkat lunak secara individual dan terisolasi dari bagian lain. Unit yang dimaksud biasanya adalah fungsi, method, atau class individual dalam kode program. Tujuan utama unit testing adalah memverifikasi bahwa setiap unit bekerja dengan benar sesuai dengan spesifikasi yang diharapkan.

Karakteristik Unit Testing:

  • Menguji unit code secara isolated (terisolasi)
  • Biasanya dilakukan oleh developer yang menulis kode
  • Automated dan dapat dijalankan berulang kali
  • Eksekusi cepat (dalam milidetik)
  • Tidak memerlukan external dependencies (database, API, file system)
  • Menggunakan mocking/stubbing untuk dependencies

Scope Unit Testing

Unit testing berfokus pada testing logic internal dari unit code:

  • Input validation dan edge cases
  • Business logic dan kalkulasi
  • Return values dan output
  • Error handling dan exception
  • Conditional statements dan loops

Analogi: Unit testing seperti memeriksa setiap komponen mobil (mesin, rem, lampu) secara terpisah sebelum merakit mobil lengkap. Ini memastikan setiap bagian berfungsi dengan baik sebelum diintegrasikan.

Keunggulan Unit Testing

Mengapa Unit Testing Penting?

Unit testing memberikan berbagai manfaat penting dalam software development:

1. Early Bug Detection

Unit testing memungkinkan developer menemukan bug di tahap awal development. Semakin awal bug ditemukan, semakin murah biaya untuk memperbaikinya. Bug yang ditemukan di tahap production bisa 10-100x lebih mahal untuk diperbaiki dibanding di tahap development.

2. Code Quality Improvement

Menulis unit test mendorong developer untuk menulis kode yang lebih modular, loosely coupled, dan maintainable. Code yang mudah di-test biasanya adalah code yang well-designed dengan separation of concerns yang baik.

3. Documentation

Unit test berfungsi sebagai living documentation yang menunjukkan bagaimana code seharusnya digunakan. Developer baru dapat memahami functionality dengan membaca test cases.

4. Refactoring Confidence

Dengan unit test yang comprehensive, developer dapat melakukan refactoring dengan percaya diri. Jika setelah refactoring semua test masih pass, kemungkinan besar refactoring tidak merusak functionality existing.

5. Regression Prevention

Unit test mencegah regression bugs (bug yang muncul kembali setelah diperbaiki). Setiap kali ada perubahan code, unit test dapat dijalankan untuk memastikan functionality existing tidak rusak.

6. Faster Development

Meskipun menulis test memerlukan waktu, dalam jangka panjang unit testing mempercepat development karena mengurangi debugging time dan mencegah bug masuk ke production.

7. Better Design

Test-Driven Development (TDD) mendorong developer untuk memikirkan design sebelum implementasi, menghasilkan architecture yang lebih baik.

Best Practice: Idealnya, unit test ditulis bersamaan dengan production code atau bahkan sebelumnya (TDD). Ratio code coverage yang baik adalah minimal 70-80%.

Framework Unit Testing Populer

JUnit (Java)

JUnit adalah framework unit testing paling populer untuk bahasa Java. Saat ini versi terbaru adalah JUnit 5 (JUnit Jupiter).

Fitur Utama:

  • Annotations untuk mendefinisikan test methods (@Test, @BeforeEach, @AfterEach)
  • Assertions untuk verifikasi hasil (assertEquals, assertTrue, assertThrows)
  • Test lifecycle management
  • Parameterized tests
  • Test suite dan grouping
  • Integration dengan build tools (Maven, Gradle)

Contoh Syntax:

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class CalculatorTest {
    @Test
    void testAddition() {
        Calculator calc = new Calculator();
        int result = calc.add(5, 3);
        assertEquals(8, result);
    }
}

Jest (JavaScript)

Jest adalah testing framework yang dikembangkan oleh Facebook, populer untuk testing JavaScript dan TypeScript, terutama untuk React applications.

Fitur Utama:

  • Zero configuration - works out of the box
  • Snapshot testing untuk UI components
  • Mock functions dan modules
  • Code coverage reporting built-in
  • Fast parallel test execution
  • Great error messages

Contoh Syntax:

describe('Calculator', () => {
    test('adds 5 + 3 to equal 8', () => {
        const result = add(5, 3);
        expect(result).toBe(8);
    });
    
    test('subtracts 10 - 3 to equal 7', () => {
        const result = subtract(10, 3);
        expect(result).toBe(7);
    });
});

Pytest (Python)

Pytest adalah testing framework untuk Python yang powerful dan mudah digunakan. Pytest dapat menjalankan unittest dan nose test, serta test yang ditulis dengan pytest style.

Fitur Utama:

  • Simple syntax dengan assert statements biasa
  • Fixtures untuk test setup dan teardown
  • Parametrization untuk data-driven testing
  • Plugin ecosystem yang rich
  • Detailed assertion introspection
  • Support untuk unittest dan doctest

Contoh Syntax:

def test_addition():
    result = add(5, 3)
    assert result == 8

def test_subtraction():
    result = subtract(10, 3)
    assert result == 7
    
def test_division_by_zero():
    with pytest.raises(ZeroDivisionError):
        divide(10, 0)

Perbandingan Framework

JUnit: Best untuk Java ecosystem, mature dan well-documented

Jest: Best untuk JavaScript/TypeScript dan React apps, fast dan feature-rich

Pytest: Best untuk Python, simple syntax dan powerful features

Struktur Test: Pola AAA

Arrange, Act, Assert (AAA)

AAA adalah pola standar untuk menulis unit test yang clean dan readable. Setiap test case dibagi menjadi tiga bagian yang jelas:

1. Arrange (Setup)

Bagian ini menyiapkan preconditions dan inputs untuk test:

  • Inisialisasi objects yang akan ditest
  • Setup test data
  • Configure mocks dan stubs
  • Set initial state

2. Act (Execute)

Bagian ini menjalankan action atau method yang akan ditest:

  • Call method atau function under test
  • Hanya satu action utama per test
  • Capture hasil atau output

3. Assert (Verify)

Bagian ini memverifikasi bahwa hasil sesuai dengan expected:

  • Verify return values
  • Check state changes
  • Verify method calls
  • Assert exceptions jika applicable

Contoh Implementasi AAA

Contoh 1: Python dengan Pytest

def test_calculate_bmi():
    # Arrange
    height = 1.75  # meter
    weight = 70    # kg
    calculator = BMICalculator()
    
    # Act
    result = calculator.calculate(height, weight)
    
    # Assert
    assert result == 22.86  # 70 / (1.75^2)
    assert 18.5 <= result <= 24.9  # Normal range

Contoh 2: JavaScript dengan Jest

test('should calculate BMI correctly', () => {
    // Arrange
    const height = 1.75;
    const weight = 70;
    const calculator = new BMICalculator();
    
    // Act
    const result = calculator.calculate(height, weight);
    
    // Assert
    expect(result).toBeCloseTo(22.86, 2);
    expect(result).toBeGreaterThanOrEqual(18.5);
});

Contoh 3: Java dengan JUnit

@Test
void shouldCalculateBMICorrectly() {
    // Arrange
    double height = 1.75;
    double weight = 70;
    BMICalculator calculator = new BMICalculator();
    
    // Act
    double result = calculator.calculate(height, weight);
    
    // Assert
    assertEquals(22.86, result, 0.01);
    assertTrue(result >= 18.5 && result <= 24.9);
}

Tips: Gunakan blank lines untuk memisahkan ketiga bagian AAA agar test lebih readable. Beberapa developer juga menambahkan comment // Arrange, // Act, // Assert untuk kejelasan.

Assertions

Apa itu Assertions?

Assertions adalah statements yang memverifikasi bahwa kondisi tertentu adalah true. Jika assertion fails, test akan fail. Assertions adalah bagian inti dari unit testing yang menentukan apakah test pass atau fail.

Jenis-Jenis Assertions Umum

1. Equality Assertions

Memverifikasi bahwa dua nilai adalah sama:

  • JUnit: assertEquals(expected, actual)
  • Jest: expect(actual).toBe(expected) atau expect(actual).toEqual(expected)
  • Pytest: assert actual == expected

2. Boolean Assertions

Memverifikasi kondisi boolean:

  • JUnit: assertTrue(condition), assertFalse(condition)
  • Jest: expect(condition).toBeTruthy(), expect(condition).toBeFalsy()
  • Pytest: assert condition, assert not condition

3. Null/Undefined Assertions

Memverifikasi nilai null atau undefined:

  • JUnit: assertNull(value), assertNotNull(value)
  • Jest: expect(value).toBeNull(), expect(value).toBeUndefined()
  • Pytest: assert value is None, assert value is not None

4. Collection Assertions

Memverifikasi collections (array, list):

  • JUnit: assertArrayEquals(expected, actual)
  • Jest: expect(array).toContain(item), expect(array).toHaveLength(n)
  • Pytest: assert item in list, assert len(list) == n

5. Exception Assertions

Memverifikasi bahwa exception di-throw:

  • JUnit: assertThrows(ExceptionType.class, () -> method())
  • Jest: expect(() => method()).toThrow(ErrorType)
  • Pytest: with pytest.raises(ExceptionType): method()

6. Floating Point Assertions

Memverifikasi floating point dengan tolerance:

  • JUnit: assertEquals(expected, actual, delta)
  • Jest: expect(actual).toBeCloseTo(expected, numDigits)
  • Pytest: assert abs(actual - expected) < tolerance

Best Practices untuk Assertions

  • Satu test sebaiknya fokus pada satu assertion utama
  • Gunakan assertion yang paling spesifik (toBe vs toEqual)
  • Tambahkan custom error messages untuk clarity
  • Avoid multiple assertions yang tidak related dalam satu test
  • Assert both positive dan negative cases

Studi Kasus: Unit Test untuk BMI Calculator

Contoh dengan Pytest (Python)

Production Code (bmi_calculator.py):

class BMICalculator:
    def calculate(self, height_cm, weight_kg):
        if height_cm <= 0 or weight_kg <= 0:
            raise ValueError("Height and weight must be positive")
        
        height_m = height_cm / 100
        bmi = weight_kg / (height_m ** 2)
        return round(bmi, 2)
    
    def get_category(self, bmi):
        if bmi < 18.5:
            return "Underweight"
        elif 18.5 <= bmi < 25:
            return "Normal Weight"
        elif 25 <= bmi < 30:
            return "Overweight"
        else:
            return "Obese"

Test Code (test_bmi_calculator.py):

import pytest
from bmi_calculator import BMICalculator

def test_calculate_normal_weight():
    # Arrange
    calculator = BMICalculator()
    height = 170  # cm
    weight = 65   # kg
    
    # Act
    result = calculator.calculate(height, weight)
    
    # Assert
    assert result == 22.49

def test_calculate_underweight():
    # Arrange
    calculator = BMICalculator()
    
    # Act
    result = calculator.calculate(170, 50)
    
    # Assert
    assert result == 17.30
    assert calculator.get_category(result) == "Underweight"

def test_calculate_overweight():
    # Arrange
    calculator = BMICalculator()
    
    # Act
    result = calculator.calculate(170, 80)
    
    # Assert
    assert result == 27.68
    assert calculator.get_category(result) == "Overweight"

def test_negative_height_raises_error():
    # Arrange
    calculator = BMICalculator()
    
    # Act & Assert
    with pytest.raises(ValueError):
        calculator.calculate(-170, 65)

def test_zero_weight_raises_error():
    # Arrange
    calculator = BMICalculator()
    
    # Act & Assert
    with pytest.raises(ValueError):
        calculator.calculate(170, 0)

def test_get_category_boundaries():
    # Arrange
    calculator = BMICalculator()
    
    # Act & Assert
    assert calculator.get_category(18.4) == "Underweight"
    assert calculator.get_category(18.5) == "Normal Weight"
    assert calculator.get_category(24.9) == "Normal Weight"
    assert calculator.get_category(25.0) == "Overweight"
    assert calculator.get_category(29.9) == "Overweight"
    assert calculator.get_category(30.0) == "Obese"

Menjalankan Test:

# Install pytest
pip install pytest

# Run all tests
pytest test_bmi_calculator.py

# Run with coverage
pytest --cov=bmi_calculator test_bmi_calculator.py

# Run with verbose output
pytest -v test_bmi_calculator.py

Test Coverage: Contoh di atas mencakup happy path (normal cases), edge cases (boundary values), dan error cases (invalid inputs). Ini adalah best practice untuk comprehensive unit testing.
