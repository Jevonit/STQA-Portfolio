Apa itu Selenium dan Selenium WebDriver?

Selenium Suite

Selenium adalah sekumpulan tools dan libraries yang digunakan untuk automation testing pada web applications. Selenium Suite terdiri dari beberapa komponen utama yang dapat digunakan untuk berbagai kebutuhan testing:

  • Selenium IDE: Browser extension untuk record dan playback test scenarios
  • Selenium WebDriver: API untuk mengontrol browser secara programmatic
  • Selenium Grid: Tool untuk menjalankan test parallel di berbagai browser dan machines

Selenium WebDriver

Selenium WebDriver adalah komponen utama dari Selenium yang menyediakan programming interface untuk berinteraksi dengan web browsers. WebDriver mengontrol browser dari perspektif pengguna, mensimulasikan tindakan nyata seperti clicking buttons, filling forms, dan navigating pages.

Karakteristik Selenium WebDriver:

  • Mengontrol browser secara native melalui browser drivers
  • Support multiple programming languages (Python, Java, JavaScript, C#, Ruby)
  • Support multiple browsers (Chrome, Firefox, Safari, Edge, Internet Explorer)
  • Cross-platform (Windows, macOS, Linux)
  • Open source dan free to use
  • Active community dan extensive documentation

Bagaimana Selenium WebDriver Bekerja?

WebDriver architecture terdiri dari tiga komponen utama:

  1. Test Script: Code yang ditulis menggunakan Selenium API dalam bahasa pilihan
  2. WebDriver API: Interface yang mentranslate commands dari test script
  3. Browser Driver: Executable yang berkomunikasi dengan browser (chromedriver, geckodriver, dll)
  4. Browser: Browser yang akan dikontrol (Chrome, Firefox, dll)

Catatan: Setiap browser memerlukan driver yang spesifik. ChromeDriver untuk Chrome, GeckoDriver untuk Firefox, EdgeDriver untuk Edge, dll. Driver ini harus compatible dengan versi browser yang terinstall.

Kenapa Harus Selenium?

Keunggulan Selenium WebDriver

1. Open Source dan Gratis

Selenium adalah open source project tanpa biaya lisensi. Ini membuat Selenium accessible untuk individual developers, startups, dan enterprise companies.

2. Multi-Browser Support

Selenium mendukung semua major browsers, memungkinkan cross-browser testing untuk memastikan aplikasi bekerja consistent di berbagai browsers:

  • Google Chrome (ChromeDriver)
  • Mozilla Firefox (GeckoDriver)
  • Microsoft Edge (EdgeDriver)
  • Safari (SafariDriver)
  • Internet Explorer (IEDriver)
  • Opera

3. Multi-Language Support

Selenium WebDriver mendukung berbagai programming languages, memungkinkan tester menggunakan bahasa yang mereka kuasai:

  • Python (populer untuk scripting dan automation)
  • Java (enterprise standard)
  • JavaScript/Node.js (untuk web developers)
  • C# (untuk .NET developers)
  • Ruby (rapid development)

4. Cross-Platform

Test scripts dapat dijalankan di berbagai operating systems tanpa perubahan significant: Windows, macOS, dan Linux.

5. Framework Flexibility

Selenium dapat diintegrasikan dengan berbagai testing frameworks dan tools:

  • Testing frameworks: pytest, unittest, TestNG, JUnit
  • CI/CD tools: Jenkins, GitLab CI, GitHub Actions
  • Reporting tools: Allure, ExtentReports
  • Page Object Model implementation

6. Large Community

Selenium memiliki community yang besar dan active, menyediakan extensive documentation, tutorials, plugins, dan support forums.

7. Realistic User Simulation

Selenium mensimulasikan user interactions secara realistic, memberikan confident bahwa aplikasi bekerja dari perspektif end-user.

8. Parallel Test Execution

Dengan Selenium Grid, tests dapat dijalankan parallel di berbagai browsers dan machines, significantly mengurangi test execution time.

Use Case: Selenium ideal untuk regression testing, cross-browser testing, end-to-end testing, dan automation testing yang memerlukan real browser interactions.

Instalasi Selenium dengan Python

Prerequisites

Sebelum instalasi, pastikan sudah terinstall:

  • Python (versi 3.7 atau lebih tinggi)
  • pip (Python package installer)
  • Web browser (Chrome atau Firefox recommended)

Langkah 1: Install Selenium Package

Install Selenium menggunakan pip di command line atau terminal:

pip install selenium

Untuk install versi specific:

pip install selenium==4.15.0

Verify instalasi:

pip show selenium

Langkah 2: Download Browser Driver

Download driver yang sesuai dengan browser yang akan digunakan:

Option A: Manual Download

  • ChromeDriver: https://chromedriver.chromium.org/downloads
  • GeckoDriver (Firefox): https://github.com/mozilla/geckodriver/releases
  • EdgeDriver: https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/

Pastikan download driver yang compatible dengan versi browser. Extract file dan simpan di PATH system atau di project directory.

Option B: Automatic Management (Recommended)

Install webdriver-manager untuk automatic driver management:

pip install webdriver-manager

Webdriver-manager akan automatically download dan setup driver yang tepat.

Langkah 3: Verify Setup

Test instalasi dengan simple script:

from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager

# Setup ChromeDriver
driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))

# Open website
driver.get("https://www.google.com")

# Print title
print(driver.title)

# Close browser
driver.quit()

Jika script berhasil, browser akan terbuka, navigate ke Google, print title, kemudian close.

Tips: Gunakan webdriver-manager untuk development karena automatically handle driver updates. Untuk production, download specific driver version untuk consistency.

Open Browser dengan Selenium

Basic Browser Operations

1. Initialize WebDriver

Membuat instance dari WebDriver untuk browser tertentu:

# Chrome
from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager

driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))

# Firefox
from webdriver_manager.firefox import GeckoDriverManager
driver = webdriver.Firefox(service=Service(GeckoDriverManager().install()))

# Edge
from webdriver_manager.microsoft import EdgeChromiumDriverManager
driver = webdriver.Edge(service=Service(EdgeChromiumDriverManager().install()))

2. Navigate ke URL

driver.get("https://www.saucedemo.com")

# Alternative
driver.get("https://example.com")

3. Browser Navigation

# Navigate back
driver.back()

# Navigate forward
driver.forward()

# Refresh page
driver.refresh()

# Get current URL
current_url = driver.current_url
print(current_url)

# Get page title
title = driver.title
print(title)

4. Window Management

# Maximize window
driver.maximize_window()

# Set window size
driver.set_window_size(1920, 1080)

# Get window size
size = driver.get_window_size()
print(size)

5. Close Browser

# Close current tab
driver.close()

# Close browser and end WebDriver session
driver.quit()

Best Practice: Selalu gunakan driver.quit() di akhir test untuk properly close browser dan release resources. Gunakan try-finally block atau context manager untuk ensure cleanup.

Interaksi dengan Element HTML

Finding Elements (Locators)

Selenium menyediakan berbagai strategies untuk menemukan elements di halaman:

1. By ID

from selenium.webdriver.common.by import By

element = driver.find_element(By.ID, "user-name")

2. By Name

element = driver.find_element(By.NAME, "username")

3. By Class Name

element = driver.find_element(By.CLASS_NAME, "btn_action")

4. By CSS Selector

element = driver.find_element(By.CSS_SELECTOR, "input.form_input")
element = driver.find_element(By.CSS_SELECTOR, "#login-button")

5. By XPath

element = driver.find_element(By.XPATH, "//input[@id='user-name']")
element = driver.find_element(By.XPATH, "//button[text()='Login']")

6. By Link Text

element = driver.find_element(By.LINK_TEXT, "Click here")

7. By Partial Link Text

element = driver.find_element(By.PARTIAL_LINK_TEXT, "Click")

Finding Multiple Elements

elements = driver.find_elements(By.CLASS_NAME, "inventory_item")
print(f"Found {len(elements)} items")

Common Element Interactions

1. Sending Text to Input Fields

username_field = driver.find_element(By.ID, "user-name")
username_field.send_keys("standard_user")

password_field = driver.find_element(By.ID, "password")
password_field.send_keys("secret_sauce")

2. Clicking Elements

login_button = driver.find_element(By.ID, "login-button")
login_button.click()

3. Clearing Input Fields

username_field.clear()

4. Getting Element Text

error_message = driver.find_element(By.CLASS_NAME, "error-message-container")
print(error_message.text)

5. Getting Attribute Values

element = driver.find_element(By.ID, "user-name")
placeholder = element.get_attribute("placeholder")
value = element.get_attribute("value")

6. Checking Element State

# Check if displayed
is_displayed = element.is_displayed()

# Check if enabled
is_enabled = element.is_enabled()

# Check if selected (for checkboxes/radio buttons)
is_selected = element.is_selected()

Waits (Explicit and Implicit)

Implicit Wait

driver.implicitly_wait(10)  # Wait up to 10 seconds for elements

Explicit Wait

from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

# Wait until element is clickable
wait = WebDriverWait(driver, 10)
element = wait.until(EC.element_to_be_clickable((By.ID, "login-button")))

# Wait until element is visible
element = wait.until(EC.visibility_of_element_located((By.ID, "user-name")))

Best Practice: Prefer explicit waits over implicit waits untuk better control dan flexibility. Implicit waits apply globally dan dapat cause unexpected delays.

Contoh Testing SauceDemo

Test Scenario untuk SauceDemo.com

SauceDemo (https://www.saucedemo.com/) adalah demo e-commerce website yang dibuat khusus untuk testing practice.

Test Scenario 1: Successful Login

Test Case ID: TC-SD-001

Description: Verify user can login with valid credentials

Steps:

  1. Navigate to https://www.saucedemo.com
  2. Enter username: "standard_user"
  3. Enter password: "secret_sauce"
  4. Click Login button
  5. Verify user is redirected to inventory page

Test Scenario 2: Login with Invalid Credentials

Test Case ID: TC-SD-002

Description: Verify error message for invalid credentials

Test Scenario 3: Add Product to Cart

Test Case ID: TC-SD-003

Description: Verify user can add product to shopping cart

Implementation dengan Selenium Python

from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
import time

class TestSauceDemo:
    def setup_method(self):
        """Setup yang dijalankan sebelum setiap test"""
        self.driver = webdriver.Chrome(
            service=Service(ChromeDriverManager().install())
        )
        self.driver.maximize_window()
        self.driver.implicitly_wait(10)
        
    def teardown_method(self):
        """Cleanup yang dijalankan setelah setiap test"""
        self.driver.quit()
    
    def test_successful_login(self):
        """Test Case: Successful Login"""
        # Navigate to SauceDemo
        self.driver.get("https://www.saucedemo.com")
        
        # Enter username
        username = self.driver.find_element(By.ID, "user-name")
        username.send_keys("standard_user")
        
        # Enter password
        password = self.driver.find_element(By.ID, "password")
        password.send_keys("secret_sauce")
        
        # Click login button
        login_button = self.driver.find_element(By.ID, "login-button")
        login_button.click()
        
        # Verify redirect to inventory page
        wait = WebDriverWait(self.driver, 10)
        inventory = wait.until(
            EC.presence_of_element_located((By.CLASS_NAME, "inventory_list"))
        )
        
        # Assert current URL
        assert "inventory.html" in self.driver.current_url
        print("✓ Login successful test passed")
    
    def test_invalid_login(self):
        """Test Case: Login with Invalid Credentials"""
        self.driver.get("https://www.saucedemo.com")
        
        # Enter invalid credentials
        self.driver.find_element(By.ID, "user-name").send_keys("invalid_user")
        self.driver.find_element(By.ID, "password").send_keys("wrong_password")
        self.driver.find_element(By.ID, "login-button").click()
        
        # Verify error message
        error = self.driver.find_element(By.CSS_SELECTOR, "[data-test='error']")
        assert error.is_displayed()
        assert "Epic sadface" in error.text
        print("✓ Invalid login test passed")
    
    def test_add_to_cart(self):
        """Test Case: Add Product to Cart"""
        # Login first
        self.driver.get("https://www.saucedemo.com")
        self.driver.find_element(By.ID, "user-name").send_keys("standard_user")
        self.driver.find_element(By.ID, "password").send_keys("secret_sauce")
        self.driver.find_element(By.ID, "login-button").click()
        
        # Wait for inventory page
        wait = WebDriverWait(self.driver, 10)
        wait.until(EC.presence_of_element_located((By.CLASS_NAME, "inventory_list")))
        
        # Add first product to cart
        add_to_cart = self.driver.find_element(
            By.CSS_SELECTOR, 
            ".inventory_item:first-child .btn_inventory"
        )
        add_to_cart.click()
        
        # Verify cart badge shows 1 item
        cart_badge = self.driver.find_element(By.CLASS_NAME, "shopping_cart_badge")
        assert cart_badge.text == "1"
        print("✓ Add to cart test passed")
    
    def test_remove_from_cart(self):
        """Test Case: Remove Product from Cart"""
        # Login and add product
        self.driver.get("https://www.saucedemo.com")
        self.driver.find_element(By.ID, "user-name").send_keys("standard_user")
        self.driver.find_element(By.ID, "password").send_keys("secret_sauce")
        self.driver.find_element(By.ID, "login-button").click()
        
        wait = WebDriverWait(self.driver, 10)
        wait.until(EC.presence_of_element_located((By.CLASS_NAME, "inventory_list")))
        
        # Add product
        self.driver.find_element(
            By.CSS_SELECTOR, 
            ".inventory_item:first-child .btn_inventory"
        ).click()
        
        # Remove product
        remove_button = self.driver.find_element(
            By.CSS_SELECTOR,
            ".inventory_item:first-child .btn_inventory"
        )
        remove_button.click()
        
        # Verify cart badge is not displayed
        cart_badges = self.driver.find_elements(By.CLASS_NAME, "shopping_cart_badge")
        assert len(cart_badges) == 0
        print("✓ Remove from cart test passed")

# Run tests
if __name__ == "__main__":
    test = TestSauceDemo()
    
    # Test 1
    test.setup_method()
    test.test_successful_login()
    test.teardown_method()
    
    # Test 2
    test.setup_method()
    test.test_invalid_login()
    test.teardown_method()
    
    # Test 3
    test.setup_method()
    test.test_add_to_cart()
    test.teardown_method()
    
    # Test 4
    test.setup_method()
    test.test_remove_from_cart()
    test.teardown_method()
    
    print("\n✓ All tests completed!")

Running Tests dengan Pytest

# Install pytest
pip install pytest

# Run all tests
pytest test_saucedemo.py -v

# Run specific test
pytest test_saucedemo.py::TestSauceDemo::test_successful_login -v

# Run with HTML report
pytest test_saucedemo.py --html=report.html
