Definisi Test Scenario dan Test Case

Apa itu Test Scenario?

Test Scenario adalah deskripsi high-level tentang apa yang akan ditest. Test scenario menggambarkan end-to-end functionality atau user journey yang perlu diverifikasi. Test scenario lebih bersifat naratif dan tidak mencakup detail langkah-langkah spesifik.

Karakteristik Test Scenario:

  • High-level dan tidak terlalu detail
  • Fokus pada "apa yang ditest" bukan "bagaimana mentest"
  • Satu test scenario dapat mencakup multiple test cases
  • Mudah dipahami oleh stakeholder non-technical

Apa itu Test Case?

Test Case adalah dokumen detail yang berisi langkah-langkah spesifik, input data, preconditions, dan expected results untuk menguji suatu functionality. Test case bersifat lebih teknis dan granular dibandingkan test scenario.

Karakteristik Test Case:

  • Detail dan spesifik dengan step-by-step instructions
  • Mencakup test data konkret
  • Memiliki expected result yang jelas
  • Dapat diexecute dan direproduksi oleh siapa saja
  • Dapat di-automate

Perbedaan Utama: Test Scenario adalah "WHAT to test" (apa yang ditest), sedangkan Test Case adalah "HOW to test" (bagaimana mentest dengan langkah-langkah detail).

Template Test Scenario

Template standar untuk mendokumentasikan test scenario:

Komponen Test Scenario

  • Scenario ID: Unique identifier (contoh: TS-001)
  • Scenario Name: Nama deskriptif yang jelas
  • Module/Feature: Bagian aplikasi yang ditest
  • Description: Penjelasan singkat tentang scenario
  • Priority: Critical, High, Medium, Low
  • Test Cases: Daftar test case terkait

Contoh Test Scenario - Aplikasi BMI

Scenario ID: TS-BMI-001

Scenario Name: Calculate BMI with Valid Input

Module: BMI Calculator

Description: Verify that BMI is calculated correctly when user enters valid height and weight values

Priority: Critical

Related Test Cases: TC-BMI-001, TC-BMI-002, TC-BMI-003

Scenario ID: TS-BMI-002

Scenario Name: Input Validation

Module: BMI Calculator

Description: Verify that application properly validates user input and displays appropriate error messages for invalid inputs

Priority: High

Related Test Cases: TC-BMI-004, TC-BMI-005, TC-BMI-006

Scenario ID: TS-BMI-003

Scenario Name: BMI Category Display

Module: BMI Calculator

Description: Verify that correct BMI category (Underweight, Normal, Overweight, Obese) is displayed based on calculated BMI value

Priority: High

Related Test Cases: TC-BMI-007, TC-BMI-008, TC-BMI-009, TC-BMI-010

Template Test Case

Template standar untuk mendokumentasikan test case dengan detail lengkap:

Komponen Test Case

  • Test Case ID: Unique identifier (contoh: TC-001)
  • Test Scenario ID: Link ke test scenario
  • Test Case Title: Judul deskriptif
  • Description: Penjelasan singkat test case
  • Preconditions: Kondisi yang harus dipenuhi sebelum test
  • Test Steps: Langkah-langkah detail untuk execute test
  • Test Data: Input data yang digunakan
  • Expected Result: Hasil yang diharapkan
  • Actual Result: Hasil aktual (diisi saat execution)
  • Status: Pass/Fail (diisi saat execution)
  • Priority: Critical, High, Medium, Low
  • Tested By: Nama tester
  • Tested Date: Tanggal execution

Contoh Test Case - Aplikasi BMI

Test Case 1: Valid BMI Calculation - Normal Weight

Test Case ID: TC-BMI-001

Test Scenario ID: TS-BMI-001

Title: Calculate BMI for Normal Weight Range

Description: Verify BMI calculation accuracy for inputs resulting in Normal weight category

Priority: Critical

Preconditions: BMI Calculator application is loaded and accessible

Test Steps:

  1. Navigate to BMI Calculator page
  2. Enter height: 170 cm in height field
  3. Enter weight: 65 kg in weight field
  4. Click "Calculate BMI" button
  5. Observe the displayed BMI value and category

Test Data:

  • Height: 170 cm
  • Weight: 65 kg

Expected Result:

  • BMI value displayed: 22.49 (±0.01)
  • Category displayed: "Normal Weight"
  • Result is displayed within 2 seconds

Test Case 2: Input Validation - Negative Height

Test Case ID: TC-BMI-004

Test Scenario ID: TS-BMI-002

Title: Validate Negative Height Input

Description: Verify that application rejects negative height values

Priority: High

Preconditions: BMI Calculator application is loaded

Test Steps:

  1. Navigate to BMI Calculator page
  2. Enter height: -170 cm
  3. Enter weight: 65 kg
  4. Click "Calculate BMI" button
  5. Observe the error message

Test Data:

  • Height: -170 cm
  • Weight: 65 kg

Expected Result:

  • Error message displayed: "Please enter a valid positive height value"
  • BMI is not calculated
  • Input field is highlighted in red

Test Case 3: BMI Category - Underweight

Test Case ID: TC-BMI-007

Test Scenario ID: TS-BMI-003

Title: Verify Underweight Category Display

Description: Verify that Underweight category is displayed for BMI < 18.5

Priority: High

Preconditions: BMI Calculator application is loaded

Test Steps:

  1. Navigate to BMI Calculator page
  2. Enter height: 170 cm
  3. Enter weight: 50 kg
  4. Click "Calculate BMI" button
  5. Observe BMI value and category

Test Data:

  • Height: 170 cm
  • Weight: 50 kg
  • Expected BMI: 17.30

Expected Result:

  • BMI value: 17.30 (±0.01)
  • Category: "Underweight"
  • Category is displayed with appropriate color coding (e.g., blue/yellow)

Test Case 4: Empty Input Fields

Test Case ID: TC-BMI-005

Test Scenario ID: TS-BMI-002

Title: Validate Empty Input Fields

Description: Verify application behavior when calculate is clicked with empty fields

Priority: High

Preconditions: BMI Calculator application is loaded

Test Steps:

  1. Navigate to BMI Calculator page
  2. Leave height field empty
  3. Leave weight field empty
  4. Click "Calculate BMI" button
  5. Observe error message

Test Data:

  • Height: (empty)
  • Weight: (empty)

Expected Result:

  • Error message: "Please enter both height and weight values"
  • BMI is not calculated
  • Both input fields are highlighted

Format Pelaporan Bug (Bug Report)

Apa itu Bug Report?

Bug Report adalah dokumen yang mendokumentasikan defect atau issue yang ditemukan dalam aplikasi selama testing. Bug report yang baik harus jelas, detail, dan reproducible sehingga developer dapat memahami dan memperbaiki masalah dengan efisien.

Komponen Bug Report

  • Bug ID: Unique identifier (contoh: BUG-001)
  • Summary/Title: Deskripsi singkat dan jelas tentang bug
  • Description: Penjelasan detail tentang bug
  • Steps to Reproduce: Langkah-langkah untuk mereproduksi bug
  • Expected Result: Apa yang seharusnya terjadi
  • Actual Result: Apa yang sebenarnya terjadi
  • Severity: Critical, High, Medium, Low
  • Priority: Critical, High, Medium, Low
  • Environment: OS, browser, version, device
  • Test Data: Data yang digunakan saat bug terjadi
  • Attachments: Screenshot, video, log files
  • Reported By: Nama tester
  • Reported Date: Tanggal pelaporan
  • Assigned To: Developer yang ditugaskan
  • Status: New, Open, In Progress, Fixed, Closed, Rejected

Severity vs Priority

Severity: Tingkat dampak bug terhadap aplikasi (technical impact)

  • Critical: Aplikasi crash, data loss, security breach
  • High: Fitur utama tidak berfungsi
  • Medium: Fitur berfungsi tapi ada masalah
  • Low: Cosmetic issue, typo

Priority: Urgensi perbaikan bug (business impact)

  • Critical: Harus diperbaiki segera (blocker)
  • High: Harus diperbaiki sebelum release
  • Medium: Diperbaiki jika ada waktu sebelum release
  • Low: Bisa diperbaiki di release berikutnya

Contoh Bug Report - Aplikasi BMI

Bug ID: BUG-BMI-001

Summary: BMI calculation shows incorrect result for decimal weight values

Description: When entering weight with decimal values (e.g., 65.5 kg), the BMI calculator shows an incorrect BMI value. The calculation appears to round the weight incorrectly.

Steps to Reproduce:

  1. Open BMI Calculator application
  2. Enter height: 170 cm
  3. Enter weight: 65.5 kg
  4. Click "Calculate BMI" button
  5. Observe the calculated BMI value

Expected Result: BMI should be 22.66 (65.5 / (1.7)²)

Actual Result: BMI shows 22.49 (appears to use 65 instead of 65.5)

Severity: High

Priority: High

Environment:

  • OS: Windows 11
  • Browser: Chrome 118.0
  • Screen Resolution: 1920x1080

Test Data:

  • Height: 170 cm
  • Weight: 65.5 kg

Attachments: screenshot_bug_001.png

Reported By: [Nama Tester]

Reported Date: 2025-10-29

Status: New

Tips Bug Report yang Baik: Gunakan bahasa yang jelas dan objektif, sertakan screenshot atau video, pastikan bug reproducible, fokus pada satu issue per bug report, dan hindari membuat asumsi tentang penyebab bug.
