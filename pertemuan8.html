Definisi Cypress

Apa itu Cypress?

Cypress adalah modern end-to-end testing framework yang dibangun khusus untuk web modern. Cypress menyediakan complete testing solution yang mencakup test runner, assertion library, mocking, dan stubbing dalam satu package yang integrated. Berbeda dengan tools tradisional seperti Selenium, Cypress didesain from the ground up untuk developer experience yang lebih baik.

Posisi Cypress dalam Testing

Cypress terutama digunakan untuk:

  • End-to-End Testing: Testing complete user workflows dari awal hingga akhir
  • Integration Testing: Testing interaksi antara berbagai components atau modules
  • Unit Testing: Testing individual components (terutama untuk frontend components)

Cypress paling powerful untuk E2E testing karena dapat mengontrol seluruh application stack, dari UI hingga network requests.

Cypress vs Selenium

Cypress:

  • JavaScript/TypeScript only
  • Runs inside browser (same run loop as application)
  • Faster execution dan more reliable
  • Better developer experience dengan automatic waiting
  • Built-in time travel debugging
  • Limited to Chrome-family browsers (Chrome, Edge, Electron)

Selenium:

  • Multi-language support
  • Runs outside browser
  • Support semua major browsers termasuk Safari, IE
  • Lebih flexible untuk complex scenarios
  • Requires more explicit waits dan error handling

Use Case: Cypress ideal untuk modern web applications yang menggunakan JavaScript frameworks (React, Vue, Angular). Selenium lebih cocok jika butuh multi-language support atau testing di Safari/IE.

Keunggulan Cypress

1. Architecture yang Berbeda

Cypress memiliki architecture unik yang membedakannya dari testing tools tradisional:

Traditional Tools (Selenium)

  • Runs outside the browser
  • Execute remote commands through network
  • Tidak memiliki akses native ke application
  • Slower dan prone to flakiness

Cypress Architecture

  • Runs inside the browser di same run loop sebagai application
  • Direct access ke application code, DOM, dan window objects
  • Can control network traffic dan manipulate responses
  • Faster dan more reliable execution

Architecture ini memberikan Cypress kemampuan untuk:

  • Synchronously access ke application state
  • Stub dan spy on functions
  • Mock server responses
  • Control time (clocks dan timers)

2. Test Runner yang Powerful

Cypress Test Runner menyediakan interactive testing experience:

  • Real-time Reloads: Tests automatically rerun saat file changes
  • Visual Feedback: See exactly what browser sees saat test runs
  • Command Log: Detailed log dari setiap command yang diexecute
  • Screenshot dan Video: Automatic capture untuk debugging
  • Error Messages: Helpful error messages dengan exact failure reasons

3. Time Travel Debugging

Fitur signature Cypress yang sangat powerful untuk debugging:

  • Hover over commands di Command Log untuk see application state saat itu
  • See DOM snapshots untuk setiap command
  • See before dan after states untuk assertions
  • Debug menggunakan browser DevTools dengan full access ke application

4. Automatic Waiting

Cypress automatically waits untuk elements dan assertions:

  • No need untuk explicit waits atau sleeps
  • Automatically retries commands until timeout
  • Waits untuk elements to exist, be visible, be enabled
  • Waits untuk animations to finish
  • Eliminates flaky tests caused by timing issues

5. Network Traffic Control

Cypress dapat intercept dan control network requests:

  • Stub API responses untuk testing edge cases
  • Wait for specific requests to complete
  • Assert on request/response data
  • Simulate network conditions (slow, offline)

6. Developer Experience

  • Simple, intuitive API yang mudah dipelajari
  • Excellent documentation dan examples
  • Built-in assertion library (Chai)
  • No configuration required untuk basic setup
  • TypeScript support out of the box

7. Consistent Results

  • Deterministic execution untuk consistent results
  • Automatic waiting eliminates race conditions
  • Retry logic untuk assertions
  • Significantly lebih sedikit flaky tests dibanding Selenium

Statistics: Many teams report 10x faster test writing dan significantly fewer flaky tests setelah migrating dari Selenium ke Cypress.

Instalasi Cypress

Prerequisites

Sebelum instalasi Cypress, pastikan sudah terinstall:

  • Node.js (versi 14 atau lebih tinggi)
  • npm atau Yarn package manager

Verify Node.js dan npm installation:

node --version
npm --version

Langkah 1: Initialize Project

Jika belum memiliki package.json, initialize project dulu:

mkdir cypress-testing
cd cypress-testing
npm init -y

Langkah 2: Install Cypress via NPM

npm install cypress --save-dev

Atau menggunakan Yarn:

yarn add cypress --dev

Instalasi akan download Cypress binary (sekitar 100-200MB) dan install dependencies.

Langkah 3: Open Cypress

Open Cypress Test Runner untuk pertama kali:

npx cypress open

Atau tambahkan script di package.json:

{
  "scripts": {
    "cypress:open": "cypress open",
    "cypress:run": "cypress run"
  }
}

Kemudian run:

npm run cypress:open

Langkah 4: Project Structure

Setelah Cypress dibuka pertama kali, akan ter-generate folder structure:

cypress/
├── e2e/               # Test files
├── fixtures/          # Test data
├── support/           # Custom commands dan global config
│   ├── commands.js
│   └── e2e.js
└── downloads/         # Downloaded files during tests

cypress.config.js      # Cypress configuration

Langkah 5: Verify Installation

Cypress akan show example tests. Run salah satu untuk verify installation successful.

Configuration (cypress.config.js)

const { defineConfig } = require('cypress')

module.exports = defineConfig({
  e2e: {
    baseUrl: 'https://www.saucedemo.com',
    viewportWidth: 1280,
    viewportHeight: 720,
    defaultCommandTimeout: 10000,
    video: true,
    screenshotOnRunFailure: true,
    setupNodeEvents(on, config) {
      // implement node event listeners here
    },
  },
})

Tips: Set baseUrl di config untuk avoid repeating full URLs di tests. Use environment variables untuk sensitive data seperti credentials.

Struktur Test Cypress

Anatomi File Test

Test file di Cypress menggunakan struktur yang familiar bagi yang sudah mengenal Mocha atau Jest:

1. describe() - Test Suite

describe() digunakan untuk group related tests:

describe('Login Functionality', () => {
  // Tests go here
})

2. it() - Test Case

it() mendefinisikan individual test case:

it('should login with valid credentials', () => {
  // Test steps go here
})

3. before() / beforeEach()

Hooks untuk setup sebelum tests:

beforeEach(() => {
  // Runs before each test
  cy.visit('/')
})

before(() => {
  // Runs once before all tests in this block
})

4. after() / afterEach()

Hooks untuk cleanup setelah tests:

afterEach(() => {
  // Runs after each test
  cy.clearCookies()
})

after(() => {
  // Runs once after all tests
})

Complete Test Structure Example

describe('SauceDemo E2E Tests', () => {
  beforeEach(() => {
    // Visit base URL before each test
    cy.visit('/')
  })

  it('should display login page', () => {
    cy.get('#user-name').should('be.visible')
    cy.get('#password').should('be.visible')
    cy.get('#login-button').should('be.visible')
  })

  it('should login successfully', () => {
    cy.get('#user-name').type('standard_user')
    cy.get('#password').type('secret_sauce')
    cy.get('#login-button').click()
    cy.url().should('include', '/inventory.html')
  })

  afterEach(() => {
    // Clear cookies after each test
    cy.clearCookies()
  })
})

Nested describe Blocks

Untuk better organization, dapat nest describe blocks:

describe('SauceDemo Application', () => {
  describe('Login Features', () => {
    it('successful login', () => {})
    it('failed login', () => {})
  })

  describe('Shopping Cart', () => {
    it('add to cart', () => {})
    it('remove from cart', () => {})
  })
})

Best Practice: Use descriptive names untuk describe dan it blocks. Names should clearly explain what is being tested.

Perintah Dasar Cypress

1. cy.visit() - Navigate ke URL

// Navigate to full URL
cy.visit('https://www.saucedemo.com')

// Navigate to relative path (if baseUrl is set)
cy.visit('/')
cy.visit('/inventory.html')

2. cy.get() - Select Element

Menemukan elements menggunakan CSS selectors:

// By ID
cy.get('#user-name')

// By class
cy.get('.btn_action')

// By attribute
cy.get('[data-test="username"]')

// By element type
cy.get('button')

// Complex selectors
cy.get('div.inventory_item:first-child')
cy.get('input[type="text"]')

3. cy.contains() - Find by Text

// Find element containing specific text
cy.contains('Login')
cy.contains('button', 'Add to cart')
cy.contains('.error-message', 'Epic sadface')

4. cy.type() - Input Text

// Type text into input field
cy.get('#user-name').type('standard_user')

// Type with special characters
cy.get('#password').type('secret_sauce{enter}')

// Type with delay
cy.get('#user-name').type('text', { delay: 100 })

5. cy.click() - Click Element

// Click element
cy.get('#login-button').click()

// Click with position
cy.get('.dropdown').click('topRight')

// Force click (bypass actionability checks)
cy.get('.hidden-button').click({ force: true })

// Double click
cy.get('.item').dblclick()

6. Other Common Commands

clear() - Clear Input Field

cy.get('#user-name').clear()

check() / uncheck() - Checkboxes

cy.get('[type="checkbox"]').check()
cy.get('[type="checkbox"]').uncheck()

select() - Dropdowns

cy.get('select').select('option2')
cy.get('select').select(['option1', 'option2'])

submit() - Submit Form

cy.get('form').submit()

Assertions

Cypress menggunakan Chai assertions:

// Should assertions
cy.get('#user-name').should('be.visible')
cy.get('#user-name').should('have.value', 'standard_user')
cy.url().should('include', '/inventory')
cy.get('.inventory_item').should('have.length', 6)

// Multiple assertions
cy.get('#user-name')
  .should('be.visible')
  .and('be.enabled')
  .and('have.attr', 'placeholder')

// Expect assertions
cy.get('.price').then(($price) => {
  const price = parseFloat($price.text())
  expect(price).to.be.greaterThan(0)
})

Alias dan Reusability

// Create alias
cy.get('.inventory_item').as('products')

// Use alias
cy.get('@products').should('have.length', 6)
cy.get('@products').first().click()

Chain Commands: Cypress commands dapat di-chain untuk readable dan concise tests. Each command automatically waits untuk previous command to complete.

Studi Kasus: Login SauceDemo

Test Scenarios untuk SauceDemo

Scenario 1: Successful Login

Scenario 2: Failed Login with Invalid Credentials

Scenario 3: Failed Login with Empty Fields

Scenario 4: Add Product to Cart

Scenario 5: Complete Checkout Flow

Complete Implementation

File: cypress/e2e/saucedemo.cy.js

describe('SauceDemo E2E Test Suite', () => {
  
  beforeEach(() => {
    // Visit SauceDemo before each test
    cy.visit('https://www.saucedemo.com')
  })

  describe('Login Functionality', () => {
    
    it('TC-001: Should login successfully with valid credentials', () => {
      // Enter username
      cy.get('#user-name').type('standard_user')
      
      // Enter password
      cy.get('#password').type('secret_sauce')
      
      // Click login button
      cy.get('#login-button').click()
      
      // Verify redirect to inventory page
      cy.url().should('include', '/inventory.html')
      
      // Verify inventory page elements
      cy.get('.inventory_list').should('be.visible')
      cy.get('.inventory_item').should('have.length.greaterThan', 0)
      
      // Verify page title
      cy.get('.title').should('contain', 'Products')
    })

    it('TC-002: Should show error for invalid credentials', () => {
      // Enter invalid username
      cy.get('#user-name').type('invalid_user')
      
      // Enter invalid password
      cy.get('#password').type('wrong_password')
      
      // Click login
      cy.get('#login-button').click()
      
      // Verify error message is displayed
      cy.get('[data-test="error"]')
        .should('be.visible')
        .and('contain', 'Epic sadface')
      
      // Verify still on login page
      cy.url().should('not.include', 'inventory')
    })

    it('TC-003: Should show error for empty username', () => {
      // Leave username empty, enter password
      cy.get('#password').type('secret_sauce')
      cy.get('#login-button').click()
      
      // Verify error message
      cy.get('[data-test="error"]')
        .should('be.visible')
        .and('contain', 'Username is required')
    })

    it('TC-004: Should show error for empty password', () => {
      // Enter username, leave password empty
      cy.get('#user-name').type('standard_user')
      cy.get('#login-button').click()
      
      // Verify error message
      cy.get('[data-test="error"]')
        .should('be.visible')
        .and('contain', 'Password is required')
    })

    it('TC-005: Should close error message when clicking X', () => {
      // Trigger error
      cy.get('#login-button').click()
      
      // Verify error is visible
      cy.get('[data-test="error"]').should('be.visible')
      
      // Click close button
      cy.get('.error-button').click()
      
      // Verify error is hidden
      cy.get('[data-test="error"]').should('not.exist')
    })
  })

  describe('Shopping Cart Functionality', () => {
    
    beforeEach(() => {
      // Login before each cart test
      cy.get('#user-name').type('standard_user')
      cy.get('#password').type('secret_sauce')
      cy.get('#login-button').click()
      cy.url().should('include', '/inventory.html')
    })

    it('TC-006: Should add product to cart', () => {
      // Get first product name
      cy.get('.inventory_item').first()
        .find('.inventory_item_name')
        .invoke('text')
        .as('productName')
      
      // Add first product to cart
      cy.get('.inventory_item').first()
        .find('button').click()
      
      // Verify cart badge shows 1
      cy.get('.shopping_cart_badge')
        .should('be.visible')
        .and('contain', '1')
      
      // Verify button text changed to "Remove"
      cy.get('.inventory_item').first()
        .find('button')
        .should('contain', 'Remove')
    })

    it('TC-007: Should add multiple products to cart', () => {
      // Add first three products
      cy.get('.inventory_item').each(($el, index) => {
        if (index < 3) {
          cy.wrap($el).find('button').click()
        }
      })
      
      // Verify cart badge shows 3
      cy.get('.shopping_cart_badge')
        .should('contain', '3')
    })

    it('TC-008: Should remove product from cart', () => {
      // Add product
      cy.get('.inventory_item').first()
        .find('button').click()
      
      // Verify added
      cy.get('.shopping_cart_badge').should('contain', '1')
      
      // Remove product
      cy.get('.inventory_item').first()
        .find('button').click()
      
      // Verify cart badge is gone
      cy.get('.shopping_cart_badge').should('not.exist')
      
      // Verify button text is "Add to cart"
      cy.get('.inventory_item').first()
        .find('button')
        .should('contain', 'Add to cart')
    })

    it('TC-009: Should view cart with added products', () => {
      // Add product
      cy.get('.inventory_item').first()
        .find('.inventory_item_name')
        .invoke('text')
        .as('productName')
      
      cy.get('.inventory_item').first()
        .find('button').click()
      
      // Click cart icon
      cy.get('.shopping_cart_link').click()
      
      // Verify on cart page
      cy.url().should('include', '/cart.html')
      
      // Verify product is in cart
      cy.get('@productName').then((name) => {
        cy.get('.cart_item')
          .should('have.length', 1)
          .and('contain', name)
      })
    })
  })

  describe('Checkout Flow', () => {
    
    beforeEach(() => {
      // Login and add product
      cy.get('#user-name').type('standard_user')
      cy.get('#password').type('secret_sauce')
      cy.get('#login-button').click()
      
      // Add first product
      cy.get('.inventory_item').first()
        .find('button').click()
      
      // Go to cart
      cy.get('.shopping_cart_link').click()
    })

    it('TC-010: Should complete checkout with valid information', () => {
      // Click checkout
      cy.get('#checkout').click()
      
      // Verify on checkout page
      cy.url().should('include', '/checkout-step-one.html')
      
      // Fill in information
      cy.get('#first-name').type('John')
      cy.get('#last-name').type('Doe')
      cy.get('#postal-code').type('12345')
      
      // Continue
      cy.get('#continue').click()
      
      // Verify on overview page
      cy.url().should('include', '/checkout-step-two.html')
      
      // Verify product is displayed
      cy.get('.cart_item').should('have.length', 1)
      
      // Finish checkout
      cy.get('#finish').click()
      
      // Verify on complete page
      cy.url().should('include', '/checkout-complete.html')
      cy.get('.complete-header')
        .should('contain', 'Thank you for your order')
    })

    it('TC-011: Should show error for empty checkout fields', () => {
      // Click checkout
      cy.get('#checkout').click()
      
      // Click continue without filling fields
      cy.get('#continue').click()
      
      // Verify error message
      cy.get('[data-test="error"]')
        .should('be.visible')
        .and('contain', 'First Name is required')
    })
  })

  describe('Product Details', () => {
    
    beforeEach(() => {
      // Login
      cy.get('#user-name').type('standard_user')
      cy.get('#password').type('secret_sauce')
      cy.get('#login-button').click()
    })

    it('TC-012: Should view product details', () => {
      // Click first product
      cy.get('.inventory_item').first()
        .find('.inventory_item_name')
        .click()
      
      // Verify on product details page
      cy.url().should('include', '/inventory-item.html')
      
      // Verify product details are displayed
      cy.get('.inventory_details_name').should('be.visible')
      cy.get('.inventory_details_desc').should('be.visible')
      cy.get('.inventory_details_price').should('be.visible')
      cy.get('.inventory_details_img').should('be.visible')
    })

    it('TC-013: Should add product from details page', () => {
      // Go to product details
      cy.get('.inventory_item').first()
        .find('.inventory_item_name')
        .click()
      
      // Add to cart from details page
      cy.get('button').contains('Add to cart').click()
      
      // Verify cart badge
      cy.get('.shopping_cart_badge')
        .should('contain', '1')
      
      // Go back
      cy.get('#back-to-products').click()
      
      // Verify back on inventory page
      cy.url().should('include', '/inventory.html')
    })
  })

  afterEach(() => {
    // Clear cookies after each test for clean state
    cy.clearCookies()
  })
})

Running Tests

Interactive Mode (Test Runner):

npx cypress open

Headless Mode (CI/CD):

npx cypress run

# Run specific spec file
npx cypress run --spec "cypress/e2e/saucedemo.cy.js"

# Run in specific browser
npx cypress run --browser chrome

# Run with video recording
npx cypress run --video

Custom Commands (cypress/support/commands.js)

Untuk reusability, dapat membuat custom commands:

// Custom login command
Cypress.Commands.add('login', (username, password) => {
  cy.get('#user-name').type(username)
  cy.get('#password').type(password)
  cy.get('#login-button').click()
})

// Custom add to cart command
Cypress.Commands.add('addToCart', (index = 0) => {
  cy.get('.inventory_item').eq(index)
    .find('button').click()
})

// Usage in tests:
cy.visit('/')
cy.login('standard_user', 'secret_sauce')
cy.addToCart(0)  // Add first item

Best Practices: Use Page Object Model untuk organize selectors dan actions. Create custom commands untuk repeated actions. Use fixtures untuk test data management.
